# Episode-by-Episode Practice Catalog

> Generated from the repository's tracked file tree and the 83-row course tracker. This is an **asset inventory**, not proof that a lesson was completed or that every asset was opened and validated. The 83 episodes are grouped into 71 physical lesson folders; shared folders are intentionally linked from each relevant episode.

## How to use this catalog

1. Open the episode README first for the lecture context and official lesson link.
2. Open the listed source workbook/data file in the application appropriate to its type.
3. Rebuild the demonstrated steps before inspecting the PBIX/PBIT reference, where one exists.
4. Change one input condition and observe the effect.
5. Save evidence and update [your learning log](LEARNING_LOG.md) and [progress tracker](../PROGRESS_TRACKER.md).

**File types:** Excel workbooks are source/practice data; PBIX files are Power BI Desktop reports/projects; PBIT files are templates; CSV/TXT/JSON/PDF files are source formats. The exact role of each file should be confirmed from its lesson, not inferred from the extension alone.

## Cross-episode asset handling

| Asset | Recommended practice |
|---|---|
| `.xlsx` / `.xls` | Inspect sheets/tables, identify the intended object, record column types and row counts, then refresh after changing a row. |
| `.csv` / `.txt` | Check delimiter, encoding, quoting, headers, locale, and malformed rows. Keep the raw source unchanged. |
| `.pdf` | Identify table boundaries and repeated headers; compare extracted row counts and totals with the source document. |
| `.json` | Inspect record/list nesting, expand deliberately, preserve identifiers, and test missing or optional fields. |
| `.pbix` | Open in Power BI Desktop, inspect queries/model/report separately, and rebuild at least one key transformation without copying. |
| `.pbit` | Open as a template, inspect required parameters/data-source prompts, and test with a safe sample configuration. |

## Important boundaries

- A file being present does not mean its contents have been independently audited or the lesson has been completed.
- Some lesson folders are intentionally service-based and have no local binary asset.
- Several episodes share a folder and therefore share its practice files.
- Keep private credentials, account exports, and personal data out of committed evidence.
