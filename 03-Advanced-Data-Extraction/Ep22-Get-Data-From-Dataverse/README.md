## 🎯 Lesson Overview & Objectives

Connecting to Microsoft Dataverse (Power Apps / Dynamics 365). Explains Common Data Model (CDM), relational business tables, option sets, and DirectQuery vs Import from Dataverse.

**Key Skills & Concepts Covered:**
- ✅ **CommonDataService.Database Connector**
- ✅ **Querying Dynamics 365 Entities**
- ✅ **Choice/Option Set Label Resolution**
- ✅ **Enterprise Governance with Dataverse**
