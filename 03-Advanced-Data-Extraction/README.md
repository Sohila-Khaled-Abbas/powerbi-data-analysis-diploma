## 📖 Module Overview

Go beyond static files into programmatic live web data extraction. Master web scraping via HTML table parsing and browser rendering, parameterizing web queries with custom M functions, building dynamic pagination loops with List.Generate, connecting to REST APIs with token headers, querying Microsoft Dataverse, and parsing deeply nested JSON data from Facebook and Instagram.

### 🎯 Key Competencies Acquired:

- 🌟 **Web Scraping (Static & Dynamic JavaScript Rendered Pages)**
- 🌟 **Automated Multi-Page Scraping with M Custom Functions**
- 🌟 **REST API Consumption with Custom Headers & Authorization Tokens**
- 🌟 **Cursor & Stateful Pagination Loops with List.Generate**
- 🌟 **Querying Microsoft Dataverse Entities**
- 🌟 **Normalizing Multi-Layer Hierarchical JSON into Flat Tables**
