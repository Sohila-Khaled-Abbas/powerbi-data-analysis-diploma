# Contributing

Thanks for helping improve this learning repository. Contributions should make the material easier to navigate, more accurate, and more useful for hands-on practice.

## Good contributions

- Fix broken internal links or inaccurate episode references.
- Clarify a concept with a small, independently written example.
- Improve M code readability and explain assumptions.
- Add validation checks or edge cases to a practice note.
- Improve accessibility, navigation, and diagrams.
- Report issues with playlist synchronization or documentation generation.

## Before opening a change

1. Check whether the topic already has an episode or reference page.
2. Keep changes focused and preserve existing course/source links.
3. Distinguish instructor-provided material from your own notes and examples.
4. Test internal relative links and Mermaid syntax where possible.
5. Never commit credentials, tokens, private datasets, or personal information.

## Data and licensing

Only add datasets, screenshots, documents, or third-party assets when redistribution is permitted. Prefer linking to the original source when permission is unclear. Remove identifying or confidential data from examples.

## Pull request checklist

- [ ] The change has a clear learning purpose.
- [ ] Existing material and links are preserved where possible.
- [ ] Markdown headings and code fences render correctly.
- [ ] Relative links resolve.
- [ ] Examples state assumptions and expected behavior.
- [ ] No secrets or restricted data are included.
