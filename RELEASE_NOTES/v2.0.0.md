# Release 2.0.0 · Learning System & Visual Documentation

**Release theme:** move from a lecture collection to an asset-aware, evidence-based learning system.

## Highlights

### Episode-by-episode practice guidance
- Added a catalog covering all **83 episodes**.
- Mapped **150 tracked practice assets** from the repository tree across **71 physical lesson folders**.
- Linked Excel, Power BI PBIX/PBIT, CSV, TXT, JSON, and PDF files to their corresponding episode entries.
- Added an episode-specific practice focus, validation checkpoint, and suggested evidence artifact.
- Clearly marked episodes with no tracked local binary asset; those lessons may rely on live connectors, cloud services, or official external resources.

### Learning roadmaps
- Added a competency-based roadmap across the seven curriculum phases.
- Added suggested eight-week pacing, skill gates, and milestone deliverables.
- Added a repeatable learning loop: preview → watch → rebuild → experiment → explain → validate → review.
- Added a dated personal learning log and spaced-review cadence.

### Visual system
- Added seven custom SVG phase icons.
- Added three custom SVG diagrams: curriculum roadmap, learning loop, and Power Query pipeline.
- Embedded SVG diagrams into the documentation and linked the new roadmap/catalog from the repository landing page.

### Progress tracking
- Expanded the 83-row tracker with practice status, review date, and evidence link columns.
- Kept every episode uncompleted by default. No progress has been inferred from the presence of files.
- Documented a mastery rule: reproduce the task, validate the result, and explain the decisions.

## Important notes

- This release adds documentation and visual assets; it does not modify the original Excel/PBIX practice files.
- No episode is automatically marked complete.
- The episode catalog is generated from tracked filenames and course tracker metadata. Confirm workbook/report contents in Excel or Power BI Desktop before treating an output as validated.
- Some connector lessons require a live account/service and intentionally have no local data file.
- The repository remains an independent learning companion; follow the instructor's official playlist for source instruction.
